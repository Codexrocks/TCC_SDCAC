## Decisões tomadas

| Decisão | Motivo |
|---|---|
| **Duas conferências, não uma** | O parse completo precisa do PyYAML, e o `validar.py` roda no gancho de `pre-commit` de quem clonou o repositório. Depender de biblioteca para a conferência inteira faria o gancho falhar ou calar justamente em quem não instalou nada |
| A conferência da margem **sem dependência nenhuma** | Dentro de um bloco escalar o YAML exige conteúdo mais indentado que a chave que o abriu. Logo, linha não vazia na coluna 0 só pode ser chave de topo, comentário ou `---`. A lista de chaves de topo do GitHub Actions é **fechada** e tem oito nomes, então o risco de falso positivo é baixo — conferido contra os seis workflows reais |
| **Falta do PyYAML: erro em CI, aviso fora** | É o padrão que o arquivo já usava para a base não resolvida. Em CI a biblioteca está instalada, então a falta significa CI mal configurado — e check que não roda não é trava |
| **Não** tentar validar YAML à mão, sem biblioteca | Reimplementar YAML é pior que depender dele. A camada da margem é um lint de um defeito conhecido, e está declarada como tal — não se apresenta como validação completa |
| Um teste que **reprova se o CI parar de instalar o PyYAML** | Sem ele, um CI que perdesse a dependência voltaria a aprovar workflow quebrado em silêncio. É a diferença entre trava e enfeite |
| Empilhar sobre a branch do **PR #55** | Os dois mexem no `SUMMARY.md` e no índice de relatórios. É o padrão de PR empilhado do [`docs/padroes.md`](../padroes.md) |

## Consequência a conhecer

**Este PR não é julgado pela regra que ele cria.** Os workflows sobrescrevem
`scripts/*.py` com a versão da base antes de validar, então o `validar.py` que
conferir este Pull Request é o da `main`, que ainda não tem `checar_workflows()`.
A regra passa a valer do PR seguinte em diante — é o mesmo princípio descrito no
[`AGENTS.md`](../../AGENTS.md), seção 12.

Os **testes**, esses sim, rodam com o código deste PR. São eles que provam que a
conferência nova funciona antes de ela ter poder sobre alguma coisa.
