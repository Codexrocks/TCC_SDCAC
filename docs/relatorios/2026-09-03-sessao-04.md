## Decisões tomadas

| Decisão | Motivo |
|---|---|
| Criar o ruleset pela API em vez da interface | Deixa a configuração registrada como texto no relatório, reproduzível e conferível. A interface não deixa rastro do que foi marcado. |
| Lista de bypass vazia, inclusive para o dono | Regra que o dono contorna não é regra. Já existe uma segunda pessoa com acesso, então há quem aprove PR. |
| Restringir o merge a **Squash and merge** pelo ruleset | O `CLAUDE.md` já exigia squash sempre. Pelo ruleset, o GitHub some com as outras opções e a regra deixa de depender de alguém lembrar. |
| Trocar `@Codexrocks/lideranca` por `@DaviSoaresDilly` no CODEOWNERS | Time inexistente invalida o arquivo inteiro. Criar o time exigiria escopo `admin:org`, que o token não tem, e resolveria menos que a troca direta. |
| Manter comentadas as linhas por pasta do CODEOWNERS | Felipe ainda não tem acesso ao repositório. Usuário sem acesso de escrita reintroduz o mesmo erro *Unknown owner*. |
| Não rodar o teste de push direto descrito na seção 3 | Se a trava falhasse, o teste teria empurrado um commit de mentira para a `main` de um repositório público. A conferência foi feita lendo o ruleset pela API, que é prova equivalente e não escreve nada. |
| Documentar os tropeços do Windows em vez de trocar `python3` por `python` nos comandos | O workflow **Validação** roda em Ubuntu, onde `python3` é o nome correto. Trocar nos documentos quebraria a leitura de quem usa Linux ou macOS. A seção 6 explica a diferença uma vez, e o resto da documentação fica intacto. |
| Não cadastrar o secret | O assistente não manuseia token nem chave. O cadastro fica com o Davi, pela interface ou pelo `gh secret set`. |
| Abrir PR em vez de commitar na `main` | A exceção do `CLAUDE.md` dependia de não haver quem aprovasse PR. Com a Yasmin já no repositório, a condição deixou de valer. |
