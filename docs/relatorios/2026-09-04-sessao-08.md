# 2026-09-04 — Sessão 08: o espaço Artigo estava na branch errada

**Data:** 04/09/2026 · **Participantes:** Davi + Claude

## O que foi pedido

> O GitBook deve ficar na `main`, `artigo` ou `documentacao`? E como crio o
> espaço do artigo no GitBook?

## O que foi feito

- Conferido o estado real do Git Sync dos dois espaços pela API do GitBook
- Encontrada uma configuração errada que descartaria o texto do artigo
- `docs/configuracao.md` atualizado com a branch de cada espaço e como conferir
- Corrigida a numeração duplicada das seções (havia duas seções `## 6`)

## A resposta

Nenhum dos dois espaços aponta para a `main`:

| Espaço | Branch |
|---|---|
| Documentação | `gitbook/docs/documentacao` |
| Artigo | `gitbook/docs/artigo` |

O espaço **Artigo já existe** — o GitBook criou sozinho a partir do
`gitbook-docs.yaml`, junto com a Documentação. Não há espaço para criar.

## O problema encontrado

Os **dois** espaços estão apontados para `gitbook/docs/documentacao`:

```
Documentação  -> gitbook/docs/documentacao   correto
Artigo        -> gitbook/docs/documentacao   ERRADO
```

Consequência, se alguém escrever o artigo pelo GitBook antes da correção:

1. O GitBook exporta para `gitbook/docs/documentacao`
2. No merge seguinte, `gitbook-sync.yml` roda `git push --force` nessa branch
3. O texto é sobrescrito
4. O job que abre o Pull Request só dispara em `gitbook/docs/artigo`, que nunca
   recebe nada — então nada chega na `main`

O texto aparece salvo no site e some depois, sem mensagem de erro. É o mesmo
furo descrito na seção 7, só que agora na porta do artigo.

## Decisões tomadas

| Decisão | Motivo |
|---|---|
| Não mexer no Git Sync pela API | O próprio servidor MCP do GitBook diz que a ligação do Git Sync é só pela interface. Tentar por uma rota genérica de integração arriscaria derrubar também a sincronização da Documentação, que está funcionando. |
| Documentar a conferência por `curl` | A tela do Git Sync não mostra a branch de forma óbvia. Sem um jeito de conferir, o mesmo erro volta silencioso. |
| Registrar o porquê junto da tabela | A tabela sozinha não impede o erro. O que impede é entender que uma das branches é espelho forçado. |
