# Relatórios

Registro de cada sessão de trabalho com o Claude e de cada reunião da equipe.

**Por que existe:** ninguém perde o fio da meada entre uma semana e outra, e a
banca tem prova documentada de como o projeto foi construído.

## Como nomear

```
docs/relatorios/AAAA-MM-DD-sessao-NN.md      sessão com o Claude
docs/relatorios/AAAA-MM-DD-reuniao.md        reunião da equipe
```

Use o [modelo](_modelo.md) e adicione a página nova ao
[`docs/SUMMARY.md`](../SUMMARY.md).
