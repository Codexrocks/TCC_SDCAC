# 2026-11-12 — Sessão 47: a falta de uma dependência derrubava a tela inteira

**Data:** 12/11/2026 · **Participantes:** Davi · Claude Opus 5 ·
**Duração:** continuação da [Sessão 46](2026-11-12-sessao-46.md), depois do
merge do #113

## O que foi pedido

O Davi mergeou o #113 — que declara o `httpx` no `pyproject.toml` — e o painel
**continuou estourando igual**:

```
ModuleNotFoundError: No module named 'httpx'
  frontend/dashboard/cliente.py, linha 124, em obter
```

## O que foi respondido / feito

### Declarar não é instalar — e isso expôs um defeito maior

O #113 resolveu o lado do projeto: quem rodar `pip install -e .` passa a receber
o `httpx`. **Não instala nada retroativamente** no ambiente de ninguém.

Mas a pilha mostrou outra coisa, e é essa que virou correção: **a falta de uma
biblioteca derrubava a tela inteira.**

- A barra lateral trata `SourceUnavailableError` e mostra o erro numa caixa
  vermelha — é como ela reage quando a API não responde
- `ImportError` **atravessava**, e o Streamlit encerrava a página
- Junto ia a fonte **Exemplos gravados**, que não precisa de rede nenhuma e
  estava a um clique de distância

Ou seja: faltando uma dependência de um caminho opcional, o painel inteiro
morria — inclusive a parte que funcionava.

### A correção

`FonteHTTP.obter` passa a capturar o `ImportError` e a levantar
`SourceUnavailableError` com as duas saídas escritas: instalar as dependências,
ou trocar para os exemplos gravados.

É o mesmo princípio que o montador do artigo já aplica ao `python-docx`: **sem a
biblioteca, não monta e diz por quê**, em vez de estourar.

**Três casos novos** em `tests/test_cliente.py`, com `sys.modules["httpx"] =
None`: a fonte API diz o que falta; a mensagem traz as duas saídas; e a fonte de
exemplos **continua respondendo** sem o httpx — que é o que torna a falta um
aviso, e não uma parede.

### Por que a tela dele foi parar na fonte API

O padrão da barra lateral é **Exemplos gravados**, que não usa httpx. A fonte
API é escolha de quem está na tela, e o Streamlit guarda a escolha na sessão do
navegador. Não há defeito no padrão — o defeito era o que acontecia depois.

## Decisões tomadas

| Decisão | Motivo |
|---|---|
| A falta de biblioteca vira **mensagem**, não pilha | A barra lateral já tem a caixa de erro pronta, e a fonte que funciona estava a um clique |
| A mensagem nomeia **as duas saídas** | "Falta httpx" manda a pessoa procurar; "instale ou troque a fonte" resolve |
| Não mexi no padrão da barra lateral | Ele já é o certo. Mudar a tela às vésperas da avaliação heurística seria mexer no que está prestes a ser avaliado |
