## Decisões tomadas

| Decisão | Motivo |
|---|---|
| Branch no formato `<autor>/<tipo>/<assunto>` | O GitHub agrupa branches por prefixo. Com o autor primeiro, a lista de branches já responde "quem está com o quê" sem abrir o log |
| Lista fechada de autores no validador | Um prefixo livre não resolve nada: `xpto/docs/algo` passaria e não identificaria ninguém. A lista força o nome a ser de alguém do projeto |
| Não travar o padrão de branch por ruleset | *Branch name pattern* vale para toda branch criada no repositório, e o GitBook cria branches próprias ao editar a documentação pelo site. Travaria o Git Sync. A checagem ficou no `validar.py`, com o mesmo efeito prático |
| Merge restrito via segundo ruleset, e não pela lista de bypass do primeiro | Separar as duas coisas mantém `Proteção da main` sem bypass nenhum. O Davi ganha o direito de **executar** o merge, e continua obrigado a PR, aprovação de outra pessoa e check verde |
| Bypass por `OrganizationAdmin`, não por usuário | Davi é o único owner da organização. A regra fica amarrada ao papel, não a uma conta — se a liderança mudar, muda o papel, não o ruleset |
| Registrar o problema de acessibilidade sem alterar `arquitetura.md` | As faixas e pesos são da Yasmin. A correção proposta é de apresentação e fica em `usabilidade.md` até ela decidir |
| Python 3.12, e não a mais recente | `pandas` e `scikit-learn` costumam demorar a ter pacote pronto para as versões mais novas, e a instalação passa a compilar da fonte. A 3.12 é a mais segura para esta stack |
| `[tool.setuptools] packages = []` no `pyproject.toml` | Permite `pip install -e ".[dev]"` funcionar hoje, sem código nenhum e sem criar pasta vazia, que o `CLAUDE.md` proíbe |
| Relatório semanal em duas etapas — script conta, assistente interpreta | Número de relatório de banca precisa ser reproduzível. Com a contagem num script sem IA, qualquer número pode ser conferido rodando o comando |
| Instruir o workflow a não inventar número | Semana vazia é resultado válido. Relatório automático que enfeita número é pior que relatório nenhum, porque a banca confia nele |
| Marcar `<!-- FALTA CITAÇÃO -->` em três pontos de `usabilidade.md` | Porcentagem de Nielsen e Landauer, limites das faixas adjetivas do SUS e edição de Shneiderman precisam ser conferidos na fonte. O `CLAUDE.md` proíbe inventar dado acadêmico |
