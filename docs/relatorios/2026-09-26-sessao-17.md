## Decisões tomadas

| Decisão | Motivo |
|---|---|
| Markdown gerado em `docs/` em vez de GitHub Projects v2 | Versionado, publicado no GitBook e auditável pela banca no histórico do git. O Projects exigiria um PAT com escopo `project` como secret, e alterar secret é vedado à IA pelo AGENTS.md §4. Confirmado na prática: `gh project list` falhou aqui por falta de `read:project` |
| TOML, não YAML ou JSON | `tomllib` é biblioteca padrão no Python 3.12 — **zero dependência nova**. O `pyproject.toml` não tem PyYAML, e os scripts existentes usam só a padrão |
| Nenhuma IA no workflow | Diferente do `relatorio-semanal.yml`, aqui não há texto a escrever: é aritmética de data. Determinístico, reproduzível por `python3 scripts/quadro.py`, e conferível por qualquer pessoa |
| Uma branch fixa (`claude/chore/quadro-diario`), não uma por dia | Um PR que se mantém atualizado, em vez de trinta PRs abertos. E evita `git push --force`, proibido pelo AGENTS.md §4 |
| Só as tabelas que **mudam de situação** viram blocos gerados | Geradas: prazos do professor, capítulos, marcos, decisões abertas e a confirmar. À mão: a tabela das onze semanas e a de decisões fechadas. Decisão fechada não tem prazo que envelheça, e a prosa do "o que ficou" é conteúdo, não estado |
| Dois PRs, não um | O registro de uma tarefa avaliada e a correção de afirmação falsa em página pública não deviam esperar as 24 h da automação |
| Só registrar as pendências de referência, sem preencher a lista | Conferir a fonte é de quem escreveu. AGENTS.md §3: referência que a IA produziu e ninguém conferiu nunca é aceitável |
| Nada foi mergeado nem aprovado | AGENTS.md §4 e §8 |
