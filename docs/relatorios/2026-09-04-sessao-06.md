**O incidente**

- Às 13:33 (UTC) o Felipe **mergeou o [PR #2](https://github.com/Codexrocks/TCC_SDCAC/pull/2)

  `main`. Os rulesets protegem só a branch padrão. É exatamente a fragilidade
  registrada em `docs/padroes.md` na sessão anterior — *"PR empilhado depende de

  ruleset seguraram; o que cedeu foi a camada que já estava classificada como
  disciplina, não trava.

**Diagnóstico do bloqueio**

- Mesmo aprovado, o PR #1 continuou `BLOCKED`. A causa não é a regra de
  governança do projeto, e sim a opção `require_extra_approval_for_unattributed_changes`,
  que veio ligada por padrão no ruleset: como os commits carregam
  `Co-Authored-By: Claude Opus 5`, que não é conta do GitHub, o próprio GitHub
  exige uma aprovação a mais.
